# Vite Templates

Vite provides a variety of project templates to quickly set up different types of applications, including React, Vue, Svelte, and more.

## Creating a Vite Project

To create a new Vite project using the official CLI tool, run the following command:

```sh
npm create vite@latest
```

This command will prompt you to select a template and configure your project.

### Choosing a Template

After running the above command, you will be given a list of templates to choose from, including:

- **vanilla** (Basic HTML + JS)
- **vue** (Vue.js framework)
- **react** (React.js framework)
- **svelte** (Svelte framework)
- **preact** (Lightweight React alternative)
- **lit** (Modern web components)

### Running Your Project

Once your project is created, navigate to the project folder and install dependencies:

```sh
cd my-vite-project
npm install
```

Start the development server:

```sh
npm run dev
```

This will launch a Vite-powered development server with hot reloading enabled.
